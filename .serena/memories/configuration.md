# Important Configuration Files

## Application manifest
- **`manifest.xml`** — authoritative version (`<Version number="0.15.0" />`), update sources (per-branch URLs to `raw.githubusercontent.com`), and per-file SHA-1 entries that the updater verifies. Regenerated as part of release packaging.
- **`manifest.cfg`** — companion config for the manifest pipeline.

## Test / build
- **`.busted`** — busted test config. Sets `directory = "src"`, `lpath = "../runtime/lua/?.lua;../runtime/lua/?/init.lua"`, `helper = "HeadlessWrapper.lua"`, `ROOT = { "../spec" }`, and excludes the `builds` tag by default.
- **`Dockerfile`** — pins Lua 5.1.5, LuaRocks 3.7.0, LuaJIT (commit `871db2c8...`), EmmyLua debugger 1.7.1, busted 2.2.0-1, cluacov 0.1.2-1, luacov-coveralls 0.2.3-1, luautf8 0.1.6-1.
- **`docker-compose.yml`** — dev environment composition.

## Editor / tooling
- **`.editorconfig`** — whitespace + line-ending rules. Honour it.
- **`.gitattributes`** — line-ending normalization (important on Windows for the binary `runtime/` assets).
- **`.gitignore`**

## GitHub
- **`.github/workflows/`** — CI pipelines (see `integrations.md`).
- **`.github/ISSUE_TEMPLATE/`** — accuracy / application / behaviour / calculation / crash bug templates plus feature request.
- **`.github/pull_request_template.md`** — required PR description scaffold.
- **`.github/release.yml`** — release-notes generation config.

## In-repo docs (read these before changing related code)
- `docs/rundown.md` — code base orientation.
- `docs/modSyntax.md` — modifier string grammar.
- `docs/addingMods.md` — how to add a new mod.
- `docs/addingSkills.md` — how to add a new skill/gem.
- `docs/calcOffence.md` — offence calc internals.

## Runtime
- **`runtime/`** — pre-built native host. Treat as a binary dependency; updated via the `update-simple-graphic.yml` workflow rather than hand-edited.
- **`runtime-win32.zip`** — packaged win32 runtime artifact.

## Generated data — DO NOT hand-edit
Files under `src/Data/` with the header `-- This file is automatically generated, do not edit!` are produced by scripts in `src/Export/`. Change the exporter, rerun it, and commit both. `src/Data/ModCache.lua` regenerates when PoB is reloaded with `Ctrl + F5`.
