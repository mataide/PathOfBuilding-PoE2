# Tech Stack

## Primary Language
- **Lua 5.1** (with **LuaJIT** for runtime performance — pinned to upstream commit `871db2c84ecefd70a850e03a6c340214a81739f0` per `Dockerfile`)

## Runtime / Host
- **SimpleGraphic** — custom native host (`runtime/SimpleGraphic.dll`, `runtime/Path{space}of{space}Building-PoE2.exe`). Provides window, rendering (OpenGL), input, sound, filesystem, and the `LoadModule` / `PLoadModule` script-loading APIs that the Lua side uses.
- LuaJIT is tuned at boot (`jit.opt.start('maxtrace=4000','maxmcode=8192')` in `src/Launch.lua`). Pass `--no-jit` on the command line to disable JIT (useful when debugging trace-related issues).
- Headless mode: `src/HeadlessWrapper.lua` shims SimpleGraphic APIs (image handles, callbacks, `LoadModule`, etc.) so the calc/mod pipeline can run under stock Lua/LuaJIT for testing.

## Build / Packaging
- No Lua "build" step — scripts are interpreted at runtime.
- Native runtime is built separately (the `runtime-win32.zip` and `runtime/` binaries are pre-compiled artifacts shipped in-repo).
- Installer / release pipeline lives in `.github/workflows/` (`installer.yml`, `release.yml`, `beta.yml`, `builddocker.yml`).

## Test Framework
- **busted 2.2.0** (LuaRocks) — config in `.busted` (root). Spec files under `spec/System/Test*_spec.lua`.
- **luacov / luacov-coveralls** for coverage.
- **luautf8** runtime dep.

## Tooling
- **Docker / docker-compose** development environment that bundles Lua 5.1, LuaJIT, LuaRocks, busted, and the EmmyLua debugger (`Dockerfile`, `docker-compose.yml`).
- **Python 3** helper scripts (e.g., `fix_ascendancy_positions.py`).
- GitHub Actions for CI: tests, spellcheck, installer build, backport automation.

## Data Layer
- Plain Lua tables under `src/Data/` (gems, items, mods, bosses, skill stat maps, etc.). Many files are **auto-generated** by scripts in `src/Export/` — they carry the header `-- This file is automatically generated, do not edit!` and must be regenerated rather than hand-edited. Notably `src/Data/ModCache.lua` is regenerated by reloading PoB with `Ctrl+F5`.
